# 消防設備逆引きリファレンス

状況から「どう対処すべきか」をさがす、オフライン対応のPWA（Progressive Web App）です。
消防用設備の点検で見つかる不備事例と、その是正対処法をまとめた個人用リファレンスとして作られています。

**公開URL：** https://maru-aicode.github.io/shobo-setsubi-gyakubiki/

## 主な機能

- **ホーム** — 最近利用したユースケースを新しい順に表示、よく使うユースケースのランキングを表示
- **さがす** — 状況からさがす／対処・結果からさがす（逆引き）の2モード検索。タグによる絞り込みも可能
- **登録** — ユースケース（状況・対処・補足・タグ）を自分で追加・編集・削除
- **バックアップ** — データをJSONファイルとして書き出し（共有シート経由でGoogle DriveやMailに送信可）／読み込み（Google Driveアプリなどからファイルを選択してインポート）

## オフライン対応について

- データはすべて端末内のlocalStorageに保存され、サーバーには送信されません
- Service Workerがページ本体をキャッシュするため、一度開けば機内モードでも動作します
- iPhoneでは、Safariでこのページを開いた後、共有ボタン→「ホーム画面に追加」でアプリのように利用できます

## 技術構成

- 素のHTML / CSS / JavaScript（フレームワーク不使用）
- `manifest.json` / `sw.js` によるPWA対応
- GitHub Pagesで静的ホスティング

## ファイル構成

```
index.html    アプリ本体（UI・ロジック）
manifest.json PWAマニフェスト
sw.js         Service Worker（オフラインキャッシュ）
icons/        ホーム画面用アイコン
```

## 注意事項

- データはブラウザ・端末ごとのlocalStorageに保存されるため、複数端末間では自動同期されません。端末間で持ち運ぶ場合は「バックアップ」機能のエクスポート／インポートをご利用ください
- サンプルデータとして、消火器点検における代表的な不備事例と是正対処法を初期登録しています
